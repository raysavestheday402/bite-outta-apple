# CLAUDE.md

Notes for working on **Apple TV Library**, a kid-friendly launcher for the family's purchased Apple TV / iTunes kids movies and shows. It's saved to a young child's iPad home screen as **TV Library**, and tapping a poster opens that title in the Apple TV app.

- **Live site:** https://raysavesthedaylibrary.netlify.app
- **Deploys:** Netlify redeploys automatically on every push to `main`. There is no build step, so the repo root is served as-is.
- **Owner workflow:** Ray works on Windows and commits and pushes with GitHub Desktop. Write instructions for him with Windows paths and plain steps.

## Hard rules

- **Never put the child's name anywhere on the site**: not in pages, titles, alt text, the manifest, comments or commit messages that end up in served files. The header says "Apple TV Library". `python tools/check_data.py` checks for this.
- **Kids titles only.** Ratings are G, PG, TV-Y, TV-Y7, TV-G, TV-PG or NR. The one exception is *My Life as a Zucchini* (PG-13), which is kept on purpose.
- **She can't read yet.** Filters and controls must work from pictures alone (emoji chips, posters, big tap targets). Don't add anything that only makes sense as text.
- **Keep it kid-proof.** No long-press popups or callouts, no text selection (except the search box), no double-tap zoom (`touch-action: manipulation`). Don't add links that leave the app except the Apple TV links themselves.
- **Never commit API keys.** `keys.txt` is git-ignored. Don't print key values or put them in files that get committed.
- **Don't change the look casually.** The bright icon-blue background with light rays, the icon in the header and the gold "Apple TV Library" wordmark are deliberate. Ask before restyling.
- **No frameworks and no build step.** Plain HTML, CSS and JavaScript, so a push is a deploy.

## Layout

| Path | What it is |
|---|---|
| `index.html` | The whole app: markup, CSS and JS in one file. |
| `sw.js` | Service worker for offline use: the page and `data.js` load fresh when online (saved copy as fallback); posters, icons and fonts load from the saved copy and refresh in the background. Bump `VERSION` only to force-clear caches. |
| `data.js` | `window.LIBRARY`, one entry per title. **Generated by `tools/build_data.py`; don't edit by hand.** |
| `posters/` | 600px-wide JPEG covers, named by id (`001.jpg`, `015a.jpg`). Generated. |
| `icons/` | Home-screen icon, favicons, `manifest.webmanifest` (`short_name` is "TV Library"). |
| `tools/cover_rows.json` | **The title list.** The single source every script reads (through `tools/libtools.py`). |
| `tools/apple_links.json` | Direct Apple TV ids found by `find_apple_links.py` or pasted with `--set`. Committed; wins over the Covers folder's Wikidata `apple-links.json`. |
| `tools/update_library.py` / `Update Library.bat` | Runs find_apple_links → get_covers --missing → build_data → check_data. Ray's one-click update. |
| `tools/find_apple_links.py` | Searches Apple TV (UTS search API, then the tv.apple.com search page, then the iTunes Store) for titles that only have a search link. Asks Ray when unsure. |
| `tools/libtools.py` | Shared helpers: flattens rows into titles (`items()`), the remembered Covers folder (`tools/covers_folder.txt`, git-ignored), matching. |
| `tools/get_covers.py` | Downloads posters (TMDB, then fanart.tv, then Wikipedia, then Apple TV art) plus details (year, rating) and Apple TV ids (Wikidata) into the Covers folder. `--missing` only fetches titles without a cover. |
| `tools/build_data.py` | Turns `tools/Covers/` into `data.js` and `posters/`. Holds the display-name, Disney & Pixar and Holidays lists. |
| `tools/check_data.py` | Offline sanity checks to run before pushing. |

Git-ignored and never committed: `keys.txt`, `Covers/` (any level), `site_check/`. Ray keeps the original hi-res covers, `details.json` and `apple-links.json` outside the repo in `C:\Users\raysa\Claude Files\Apple TV Archive\Covers`.

## The app (`index.html`)

- One IIFE reads `window.LIBRARY` and renders either the poster **Grid** or iPod-style **Cover Flow** (swipe, scrubber, "Play in Apple TV" button).
- Filter chips: `all`, `recent`, `movies`, `shows`, `disney`, `holidays`, `plus`, `favs`. `disney`, `holidays` and `plus` come from each entry's `tags` (`"disney"`, `"holiday"`, `"plus"`).
- Apple TV+ titles (`"plus"` tag) need a subscription, so they only show under the ➕ Apple TV+ chip, in Favorites and in search results, and aren't in the header count. Set `PLUS_EVERYWHERE = true` in `index.html` to mix them in. The chip hides itself when no title has the tag.
- **Recent** (Recently Watched) lists the titles last opened in Apple TV, newest first (up to 24).
- **No Wi‑Fi:** when `navigator.onLine` is false, a red "No Wi‑Fi" alert pinned in the toolbar shows a green **Open Downloads** button (`videos://`, iPhone/iPad only) into the Apple TV app, where downloaded titles still play. A web page can't see the TV app's downloads, so it can't list them itself.
- The Cover Flow stage has `touch-action: none`, so swipes on the covers never scroll the page. The title and buttons under it still scroll, so small screens can reach Play.
- **Link check (grown-ups only):** `?test=1` turns it on for that device and `?test=0` (or the bar's button) turns it off. It adds a 🔗 Check links chip (broken first, then search links, then everything not yet marked working), broken-link flags on posters, ✅ Works / ❌ Broken buttons on each title, and a Copy results button that copies a plain-text report to paste to Claude. The kid never sees any of it.
- Per-device state in `localStorage` under `rstd:favs`, `rstd:chip`, `rstd:view`, `rstd:recent`, `rstd:marks` and `rstd:test`, always through the `lsGet` / `lsSet` try/catch wrappers.
- Movies are listed before shows. Sorting ignores a leading "The/A/An".
- Escape any library text with `esc()` and links with `safeUrl()` when building HTML.

## A `data.js` entry

```js
{ "id": "101", "title": "PAW Patrol: The Dino Movie", "kind": "movie", "year": "2026", "rating": "PG",
  "poster": "posters/101.jpg", "link": "https://tv.apple.com/us/movie/<slug>/umc.cmc.…", "direct": true, "tags": [] }
```

`direct: false` means no Apple TV id was found and `link` is an Apple TV search for the title instead.

## `cover_rows.json` fields

| Field | Meaning |
|---|---|
| `n` | Row number. It becomes the id and the file prefix (`001`). Append new titles with the next free number; never renumber, because favorites are saved by id. |
| `kind` | `"movie"` or `"tv"`. |
| `label` | Internal name. It's the key for `DISPLAY`, `DISNEY`, `HOLIDAY` and `NO_YEAR` in `build_data.py`, and the shown title unless `DISPLAY` overrides it. |
| `term` | What to search TMDB for. |
| `year` | Release year to pick the right match, or `""`. |
| `mode` | `""` normally, `"skip"` to leave the row out, `"multi"` for rows with special handling. |
| `wiki` | Exact Wikipedia page titles, used as a fallback poster source and for Wikidata ids. |
| `alts` | Other names to try on TMDB. |
| `choices` | Splits one row into several titles (`015a`, `015b`…), each with its own `kind`, `term`, `year` and optional `title`, `alts`, `apple`, `tags`. Used for collections (Halloweentown, `010a`–`010d`) so each movie gets its own link. Until a choice has its own cover, it borrows the row's old cover (`010 - ….jpg`). |
| `title` | Optional name to show (otherwise `DISPLAY` or `label`). |
| `apple` | Optional search term for Apple TV if it differs from `term`. |
| `tags` | Optional extra tags: `"plus"` for Apple TV+, `"holiday"`, `"disney"`. |

Rows 151 and up are the Apple TV+ kids & family titles.

## Updating the library

1. Add or edit rows in `tools/cover_rows.json`. Mark Disney/Pixar or holiday titles with `tags` (or add the `label` to `DISNEY` / `HOLIDAY` in `tools/build_data.py`), and give a `title` if the label isn't the name to show.
2. `pip install -r tools/requirements.txt` (once).
3. `python tools/update_library.py ["path\to\Covers"]` (or double-click `tools/Update Library.bat`). Ray's Covers folder is `C:\Users\raysa\Claude Files\Apple TV Archive\Covers`; the path is remembered after the first run. It finds Apple TV links, downloads covers only for titles without one (so the two hand-added covers, *The Land of Sometimes* and *A Scooby-Doo! Valentine Bouquet*, are kept), rebuilds `data.js` and `posters/`, and runs the checks.
4. Check new covers by eye, then commit and push. Netlify deploys in about a minute.

For a title that still opens a search: `python tools/find_apple_links.py --set <id> "<tv.apple.com link>"` (Ray gets the link from the Apple TV app's Share → Copy Link). A full re-download of every cover is `python tools/get_covers.py` with no flags.

The scripts need network access to TMDB, fanart.tv, Wikipedia, Wikidata and Apple (uts-api.itunes.apple.com, tv.apple.com, itunes.apple.com), which a cloud session may not have. Without it, edit only what doesn't need downloads and let Ray run step 3 locally.

## Testing changes

There is no test suite. For app changes, serve the folder (`python -m http.server`) and check it in a browser at iPad sizes (portrait and landscape) and phone width, in both Grid and Cover Flow, with each filter chip. For offline, use the browser's offline mode after one load and reload. The real check is Safari on the iPad from the home-screen icon. For data changes, run `tools/check_data.py`.

## Play vs Buy on the iPad

A poster shows **Play** only if the iPad's Apple Account owns the title (Family Sharing with Purchase Sharing on counts), the purchase isn't hidden, and Screen Time allows the rating. That's account setup, not something the site can fix.
